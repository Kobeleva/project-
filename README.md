# Адаптивность проекта Willow

Адаптивность веб-страницы выполнена под следующие типы устройств:
* **Десктопная версия**: 1440px (исходный фрейм Figma).
* **Мобильная версия**: контрольная точка (breakpoint) настроена на **430px** и ниже (полностью оптимизировано под экраны современных смартфонов, включая Google Pixel 7 с разрешением 412x915px).

### Особенности мобильной адаптации:
1. Крупные многоколоночные сетки `Grid` и `Flexbox` перестраиваются в одну вертикальную колонку (`flex-direction: column`).
2. Внутренние и внешние отступы уменьшены для экономии пространства на маленьких экранах.
3. Элементы не вылезают за границы контейнеров за счет использования адаптивных единиц и свойства `box-sizing: border-box`.
4. Горизонтальный скролл полностью отсутствует.
